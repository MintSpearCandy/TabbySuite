# TabbySuite CHANGELOG

## 1.0.237-s2 — 2026-10-07T12:58:45.884Z

- core: 1.0.237（官方 portable 原样）
- tabby-webviewer 0.4.9 **(dirty)**
  > 录制条目多选的取消行为补全、划选手势语义修正、页签栏造型重做、窄窗格适配。
  > 
  > ## 改进
  > 
  > - **窄窗格适配**：
  >   - **工具栏换行**：录制窗格太窄时，toolbar 不再挤压/重叠——页签条保持
  >     完整不截断，工具栏（过滤器/操作按钮）自动换行到第二行，操作按钮仍
- tabby-hotkey-guard 0.2.1
- tabby-glass-theme 0.4.0
- tabby-output-filter 0.5.7
- tabby-better-configer 0.1.0 **(dirty)**
- tabby-terminal-workwench 0.2.0
  > 相对 0.1.0 的完整变更（数据层重构、右键管理与设置页重设计、快捷搜索与热键、JS/文件模板块等）：
  > 
  > 
  > - 文件块并入收集弹窗：带 `{{file}}` 标签的按钮不再串行弹系统对话框，而是与参数行**同一个弹窗**收集——每个文件标签一个拖放块，点击调用系统文件选择接口，**拖入文件（或拖入文本路径）自动填入**；显示文件名/路径、可清除重选；全部选齐前执行按钮禁用。标题按内容自适应（填写命令参数 / 选择文件 / 填写参数与选择文件）。
  > - 新增 **JS 块** `{{js: ...}}`：执行瞬间在独立 vm 沙箱求值并嵌入结果。单表达式自动包裹、含语句关键字（return/throw/let/if…）按函数体执行；可跨行、字符串/花括号内 `}}` 不误终止；500ms 超时杀死同步死循环。注入上下文：`params`（参数值）、`files`（文件块句柄）、`clipboardText`、`session`（目标会话元数据 + **终端输出快照**：xterm buffer 纯文本最近 50 行——可直接解析设备输出）、`now`、`os`。求值失败中止执行，未解析标签绝不进终端。
  > - 新增 **文件块** `{{file}}` / `{{file:key}}`：标签渲染为所选文件绝对路径；命名块在 JS 中经 `files.<key>` 引用 `name/stem/ext/path/dir/size/sizeMB/mtime` 与惰性 `text`（≤256KB）。`file` 成为参数保留名。
  > - 渲染管线统一：收集弹窗（参数 + 文件）→ JS 求值 → 常规替换（fill/copy 共用；copy 同样可读会话快照）。编辑器新增「插入文件」「插入 JS」按钮与说明。
